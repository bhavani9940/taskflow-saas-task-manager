# TaskFlow - SaaS Task Manager

## Production Capstone Project

TaskFlow is a production-style responsive SaaS task management
application developed as a final capstone project.

### Technologies

- HTML5
- CSS3
- JavaScript ES6+
- LocalStorage
- Responsive Design
- CSS Grid
- Flexbox

### Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- Filter All / Active / Completed
- Search tasks dynamically
- Priority management
- Completion percentage
- Dashboard statistics
- Dark mode
- Persistent browser storage
- Responsive mobile/tablet/desktop design
- Accessible buttons and form controls
- Modular client-side state management

### Project Structure

saas_task_manager/
│
├── index.html
├── style.css
├── script.js
└── README.md

### How to Run

Open `index.html` in Google Chrome, Microsoft Edge,
Firefox, or another modern web browser.

No external libraries are required.

### Deployment

This project is suitable for deployment using:

- GitHub Pages
- Vercel
- Netlify

### Capstone Goal

The project demonstrates the integration of frontend development,
responsive design, JavaScript DOM logic, state management,
browser storage, and production-style UI architecture.
